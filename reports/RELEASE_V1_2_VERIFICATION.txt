Код C++ и включённые ресурсы не изменены относительно проверенной копии.
Компилятор не нужен обычному игроку. На проверочной системе он установлен,
но исключён из PATH дочернего процесса; отдельная чистая VM не проверялась.
На хосте есть Windhawk: внедрённые им модули перечислены отдельно
от настоящих PE-зависимостей приложения.
Физические клавиши при активной CS2, видимость поверх игры и слышимость
динамиков требуют ручной проверки.

Публикация выполняется отдельным workflow Release v1.2:
проверка точных локально протестированных исходников/ресурсов,
новая Windows x64 сборка, модели/парсер и фактический runtime smoke,
проверка ZIP, загрузка и проверка байтов черновика, публикация,
проверка публичных ссылок и неизменности Release/тега v1.1.
В этой версии исходного отчёта публикация ещё не объявляется успешной:
результат нужно сверять с reports/RELEASE_PUBLICATION_RESULT.json
в артефакте завершённого workflow и фактической страницей Release.
CI-сборка имеет собственные SHA256, которые могут отличаться от локальной
сборки из-за отметки времени PE и версии установленного компилятора.
Публичные файлы проверяются по хешам именно CI-сборки.
