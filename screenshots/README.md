# Current interface screenshots

Generated from synthetic regression fixtures on Windows using the actual WinAPI/GDI HUD.
No personal console.log, INI, CSV or session history is included.

- `players_modern.png`, `players_cs16.png`: player column and selected attempt.
- `players_*_analysis.png`: player names in analysis, including very long names.
- `players_*_unknown.png`: anonymous/unknown player.
- `goals_*.png`: threshold/goal settings, remaining distance and reached goal.
- `review_modern_diagonal.png`, `review_cs16_compare.png`: analysis/comparison.
- `console_modern_live.png`: source status example.

LOG ERROR in a fixture screenshot indicates that no game log was configured for
that particular GUI test, not an unexplained runtime failure. Runtime and manual
CS2 limitations are recorded in VERIFICATION_RU.txt.
