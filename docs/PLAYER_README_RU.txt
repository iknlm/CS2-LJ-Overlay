СКАЧАТЬ И ЗАПУСТИТЬ
1. Скачайте LJOverlay_v1.2_win64.zip.
2. Распакуйте архив в доступную для записи папку.
3. Запустите LJOverlay_new.exe.
4. При необходимости укажите путь к console.log.

Для обычного запуска компилятор, MSYS2, Python и инструменты разработчика
не нужны. Сохраните папку sounds рядом с EXE. Не запускайте программу из ZIP.

НАСТРОЙКА CS2
Добавьте -condebug в параметры запуска CS2 в Steam и перезапустите игру.
Используйте оконный или безрамочный режим. Лог: game/csgo/console.log.
Если автоматический поиск не сработал: INS -> 9 -> 10, введите путь к логу.
Программа работает отдельно от игры, не внедряет DLL и не меняет процесс CS2.

КЛАВИШИ И НАСТРОЙКИ
INS — настройки внутри HUD. F6/F7 — GOOD/BAD последнего прыжка.
F8 — вернуть автооценку. F9 — закрепить HUD и пропускать клики.
Home — скрыть/показать. Ctrl+End — выйти.
Старую попытку отмечайте через INS -> История; F6/F7/F8 всегда меняют последнюю.
В настройках выберите Modern или CS 1.6.
Звуки по умолчанию выключены и воспроизводятся только в теме CS 1.6.
INS -> 10 — звуки и громкость.
INS -> 11 — пороги успеха и отдельные цели для типа прыжка и режима.
Ручное значение WR не объявляется официальным мировым рекордом.

КОНФИГУРАЦИЯ И ОБНОВЛЕНИЕ
Файл lj_overlay.ini создаётся автоматически при первом запуске.
Можно заранее скопировать lj_overlay.ini.example в lj_overlay.ini.
Шаблон не содержит личного пути к логу или ника.
При обновлении сохраните свои lj_overlay.ini, lj_history.dat и lj_jumps/.
Закройте программу перед заменой EXE и ресурсов.
Отдельный EXE подходит для обновления уже распакованной установки;
он не содержит внешних звуков. Для первой установки используйте полный ZIP.
При отсутствии sounds HUD продолжает работать без недостающих звуков.

ПРОВЕРКИ
EXE Windows x64 собран со статической линковкой GCC/libstdc++.
Зависимости — системные DLL Windows. Запуск проверен без путей компилятора
в PATH; отдельная виртуальная машина без установленного компилятора
и все версии Windows не проверялись.
Проверены WAV и вызовы звукового API; слышимость динамиков и физическое
взаимодействие при активной CS2 требуют ручной проверки на вашем компьютере.
